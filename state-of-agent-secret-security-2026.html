What broke in 2026

The incidents this year share a pattern: the agent held a secret, and an attacker got the agent to reveal or misuse it.

  • GhostSplice - splits instructions across MCP channels so an AI coding agent recombines them and exfiltrates SSH keys, secrets, and source code. [5]
  • Poisoned tool descriptions - Microsoft showed an agent can be hijacked by nothing more than a malicious MCP tool description, quietly handing company data to an outsider. [6]
  • SmartLoader - a three-month supply-chain operation shipped a trojanized MCP server that stole wallets, API keys, SSH keys, and session tokens. [7]
  • Amazon Q Developer - a CVSS 8.5 flaw let a workspace MCP config execute code and exfiltrate AWS credentials without consent. [3]

Why environment variables fail for agents

Storing a secret in an env var was fine for a web server that reads a key, signs one outbound request, and never exposes it again. An agent is different, and opens several leak paths a server never had:

  • The context window. Agents assemble prompts from many sources; a key in the environment or a config object easily gets serialized into a prompt, a system message, or a tool description that travels to a third-party inference API.
  • Tool-call arguments. Tool arguments are model-generated text. A prompt-injected model can be steered into placing a held secret into an argument, a log line, or a reply.
  • Logs and traces. Agent frameworks log prompts, completions, and tool I/O by default. Any secret that touches that pipeline is a secret in your logs.

That is why the MCP-server study found leaks above 10 percent: the credentials were sitting where the model could reach them.

The defenses that actually hold

Guidance across OWASP and the 2026 research converges on defense in depth, but the layers are not equal.

  1. Screen untrusted input before the agent acts on a web page, tool result, or message. Necessary, but pattern-matching never catches everything.
  2. Least privilege and human-in-the-loop for high-risk actions. Reduces blast radius, does not stop exfiltration of what the agent holds.
  3. Structural: keep the secret out of the agent entirely. This is the only layer that does not depend on the model getting it right. If the agent never possesses the raw key, a fully compromised model has nothing to leak.

The first two are about making the model behave. The third removes the thing being stolen. A prompt-injection defense that depends on the model is only as good as the model, the wording, and the temperature, all of which change. Structural controls do not.
